# TokenBaseball — 기능 구현 목록 v0.2

기준: [앱 기획서](앱-기획서.md). v0.1의 ‘볼’ 재화·카드 상점·포지션 자유 배치 항목은 아래 변경 사항으로 대체한다.

체크 표시는 구현 완료를 뜻한다. 수동 화면 검수 여부는 [검증 결과](구현-검증-결과.md)를 따른다.

## 검증 기준

1. 새 저장 위치에서 루키 9명과 완성된 선수단으로 시작하고, 재실행해도 같은 카드·이름을 유지한다.
2. 49,999,999토큰에서는 뽑기 0장, 50M에서 1장, 100M에서 2장을 지급한다. 중복 반영으로 늘지 않는다.
3. 뽑은 선수의 등급·이름·포지션은 생성 시 결정되고, 포지션은 수정하거나 다른 자리에 배치할 수 없다.
4. 오늘 기록만 상태바에 합산한다. 자정·시간대 변경·과거 기록 반영에도 날짜별 합계가 맞는다.
5. v0.1 파일 변환과 실패 처리에서 원본·카드·수정 이름·사진을 보존한다.
6. 야구장 상단과 목록 하단에서 동일한 선수·포지션이 보이고 교체 결과가 함께 반영된다.

실행 환경·테스트 결과·남은 제한은 [구현 및 검증 결과](구현-검증-결과.md)에 기록한다. 현재 버전은 사용자 요청으로 확정된 50M·75/20/5 정책을 적용한다.
