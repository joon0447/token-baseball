# TokenBaseball — 앱 기획서

> 앱 이름: TokenBaseball · 버전: v0.1 · 작성일: 2026-09-16 · 수정일: 2026-09-17
>
> 사용자가 제시한 요구사항을 바탕으로 작성한 초안입니다. 추가한 기획 방향은 **제안**, 아직 정하지 않은 정책은 **미정**으로 표시했습니다.

## 1. 서비스 개요

사용한 AI 토큰량을 앱 내 재화로 전환하고, 그 재화로 선수 카드를 구매해 나만의 야구단을 구성하는 macOS 프로그램입니다.

AI를 사용한 기록이 선수 카드 수집으로 이어지고, 선수의 이름과 프로필 사진을 직접 바꾸며 자신만의 선수단을 만드는 경험을 제공합니다.

## 2. 확정 요구사항

| 구분 | 내용 |
| --- | --- |
| 앱 이름 | TokenBaseball |
| 실행 환경 | macOS에서 실행되는 프로그램 |
| 재화 | 사용한 AI 토큰량을 기반으로 획득 |
| 카드 구매 | 획득한 재화로 선수 카드 구매 |
| 선수단 구성 | 보유한 선수 카드로 선수단 구성 |
| 카드 등급 | 총 3개 등급으로 구분 |
| 선수 이름 | 최초에는 가명으로 제공하며, 사용자가 변경 가능 |
| 프로필 사진 | 최초에는 기본 이미지로 제공하며, 사용자가 변경 가능 |

## 3. 핵심 이용 흐름

1. AI 토큰 사용량을 앱에 반영합니다. 반영 방식은 미정입니다.
2. 반영된 토큰 사용량에 따라 재화를 획득합니다.
3. 카드 상점에서 재화를 사용해 선수 카드를 구매합니다.
4. 보유 카드에서 선수를 선택해 선수단에 배치합니다.
5. 선수 이름과 프로필 사진을 변경해 선수단을 꾸밉니다.
6. 이후 누적되는 AI 사용량으로 카드를 추가 구매하고 선수단을 교체합니다.

## 4. 토큰 및 재화

### 4.1 기본 구조

**제안:** 사용 기록을 보여주는 누적 토큰량과 카드 구매에 쓰는 재화 잔액을 분리합니다.

| 항목 | 의미 |
| --- | --- |
| 누적 인정 토큰량 | 앱에서 재화 산정 대상으로 인정한 AI 사용량 |
| 누적 획득 재화 | 인정 토큰량을 기준으로 지금까지 지급한 재화 |
| 사용한 재화 | 카드 구매에 소비한 재화 |
| 보유 재화 | 현재 카드 구매에 사용할 수 있는 잔액 |

- 카드 구매 시 보유 재화만 차감하며, 누적 토큰 기록은 유지합니다.
- 동일한 사용 기록에 대해 재화를 중복 지급하지 않습니다.
- 재화가 부족하면 구매를 완료할 수 없으며, 필요한 추가 재화를 표시합니다.
- 사용량을 가져오지 못한 경우 기존 기록과 잔액을 유지하고 상태를 안내합니다.

**미정:** 지원할 AI 서비스, 사용량 수집 방식, 입력·출력·캐시 토큰의 인정 범위, 연동 이전 사용량 인정 여부, 재화 명칭, 환산 비율 및 소수점 처리 기준.

### 4.2 카드 구매

**제안:** 첫 버전은 원하는 카드 한 장을 선택해 구매하는 방식으로 구성합니다. 구매 전에 선수 정보, 등급, 가격을 확인할 수 있도록 합니다.

- 구매가 완료되면 재화를 차감하고 보유 카드에 추가합니다.
- 구매 실패 시 재화 차감과 카드 지급이 서로 어긋나지 않도록 처리합니다.
- 무작위 카드 팩을 사용할지는 별도 결정합니다.

**미정:** 카드 가격, 등급별 가격 차이, 상점에 노출할 카드 종류 및 갱신 방식, 동일 선수 카드의 중복 구매 허용 여부.

## 5. 선수 카드

### 5.1 등급명 추천

**제안: 루키 → 올스타 → 레전드**

야구 용어로 구성해 친숙하고, 세 등급의 순서를 쉽게 이해할 수 있는 이름입니다. 여기서 등급명은 카드의 분류이며, 선수의 실제 경력이나 나이를 뜻하지 않습니다.

| 등급 | 명칭 | 카드 콘셉트 제안 |
| --- | --- | --- |
| 1등급 | 루키 | 선수단의 기본 구성을 채우는 카드 |
| 2등급 | 올스타 | 수집의 주요 목표가 되는 상위 카드 |
| 3등급 | 레전드 | 가장 높은 등급의 특별한 카드 |

등급별 희소성, 가격, 능력치 차이는 미정입니다. 경기 기능 도입 여부가 정해지기 전까지 능력치는 필수 항목으로 두지 않습니다.

### 5.2 카드 정보

| 항목 | 내용 | 상태 |
| --- | --- | --- |
| 선수 이름 | 최초 가명 제공, 사용자 변경 가능 | 확정 |
| 프로필 사진 | 최초 기본 이미지 제공, 사용자 변경 가능 | 확정 |
| 카드 등급 | 3개 등급 중 하나 | 확정 |
| 포지션 | 선수단 배치 시 참고하는 수비 포지션 | 제안 |
| 카드 식별값 | 이름과 사진이 바뀌어도 같은 카드를 식별 | 제안 |

### 5.3 이름 및 사진 변경

**제안:** 보유 카드의 상세 화면에서 이름과 사진을 수정할 수 있도록 합니다.

- 선수 이름은 공백만 있는 값으로 저장할 수 없습니다.
- 프로필 사진은 Mac의 이미지 파일을 선택해 변경합니다.
- 사진을 적용하기 전에 표시 영역을 미리 확인할 수 있습니다.
- 변경한 이름과 사진은 보유 카드 목록과 선수단 화면에 함께 반영합니다.
- 이름과 사진을 바꾸어도 카드 등급과 카드의 식별값은 유지합니다.
- 기본 이름과 기본 사진으로 되돌리는 기능을 제공합니다.

**미정:** 이름 길이 제한, 지원 이미지 형식과 용량, 같은 선수를 중복 보유할 경우 변경 내용을 적용할 범위.

## 6. 선수단 구성

보유한 선수 카드를 선택해 선수단에 등록하고, 등록된 선수를 다른 보유 카드로 교체할 수 있습니다.

**초기 구성 제안:** 아래의 기본 수비 포지션 9개에 선수를 배치합니다.

| 구분 | 포지션 |
| --- | --- |
| 투수·포수 | 투수, 포수 |
| 내야수 | 1루수, 2루수, 3루수, 유격수 |
| 외야수 | 좌익수, 중견수, 우익수 |

- 카드가 부족한 포지션은 빈 상태로 유지할 수 있습니다.
- 동일한 카드 한 장을 여러 자리에 동시에 배치할 수 없습니다.
- 선수단에서 제외한 카드는 보유 카드 목록에 남습니다.
- 선수 교체는 카드를 소비하지 않습니다.
- 후보 선수를 포함한 전체 보유 카드는 별도 목록에서 확인합니다.

**미정:** 최종 선수단 정원, 포지션별 배치 제한, 지명타자 사용, 선발·불펜 구분, 타순 설정, 구단 이름 변경 기능.

## 8. 첫 버전 범위 제안

첫 버전의 완성 기준은 **AI 사용량 반영 → 재화 획득 → 카드 구매 → 선수단 구성 → 선수 꾸미기**의 흐름을 사용할 수 있는 것입니다.

- 토큰 사용량 반영 방식 1개 지원
- 사용량에 따른 재화 지급 및 잔액 관리
- 3개 등급의 선수 카드와 구매 기능
- 보유 카드 조회 및 선수단 배치·교체
- 선수 이름 및 프로필 사진 변경
- 앱을 종료해도 재화, 보유 카드, 선수단, 수정한 이름과 사진 유지

경기 시뮬레이션, 선수 육성, 카드 합성·거래, 다른 사용자와의 대결은 후속 검토 대상으로 둡니다.
