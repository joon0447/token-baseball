# TokenBaseball — 앱 기획서 v0.2

수정일: 2026-09-17. 기존 기획에 사용자의 변경 요청을 반영한 현재 기준 문서다.

## 서비스 개요

Codex와 Claude Code의 AI 토큰 사용 기록을 반영하고, 일정 사용량마다 받는 뽑기 카드로 야구 선수를 모으는 macOS 프로그램이다. 첫 실행부터 기본 선수단을 제공한다.

## 기본 선수단

- 첫 실행 시 기본 수비 포지션 9개에 각각 선수 1명을 제공하고 자동 배치한다.
- 기본 선수는 모두 최하위 등급인 루키이며, 이름은 무작위로 생성한다.
- 재실행 때 이름을 다시 생성하거나 기본 선수를 중복 지급하지 않는다.
- 이름·사진은 사용자가 바꿀 수 있지만 포지션은 고정이다.

## 토큰과 선수 획득

- ‘볼’ 재화와 카드 상점을 제거한다. 사용량을 토큰 수로 표시하며 K·M·B 단위를 사용한다.
- 누적 인정 토큰 **50M마다 뽑기 카드 1장**을 지급한다.
- 뽑기 카드 1장을 열면 선수 카드 1장을 받는다. 누적 토큰은 차감하지 않는다.
- 선수의 등급, 최초 이름, 포지션은 무작위로 정한다.
- 등급 확률은 **루키 75% / 올스타 20% / 레전드 5%**다.
- 포지션은 기본 수비 9개 중 동일 확률로 선택한다. 이름·포지션이 같은 서로 다른 카드를 보유할 수 있다.
- 동일 사용 기록은 중복 집계하지 않는다. 미사용 뽑기 카드는 앱을 종료해도 유지한다.

## 선수 수정과 배치

- 선수 이름과 프로필 사진은 기존과 같이 수정·기본값 복원할 수 있다.
- 선수 포지션을 변경하는 기능은 제공하지 않는다.
- 선수단에서도 해당 선수의 고정 포지션에만 배치할 수 있다.
- 선수 교체·제외는 카드를 소비하지 않으며, 같은 카드 한 장을 여러 자리에 놓을 수 없다.

## 화면 구성

| 화면 | 기능 |
| --- | --- |
| 홈 | 오늘·누적 토큰, 뽑기 카드 수, 다음 지급까지의 진행도, 선수단 요약 |
| 선수 뽑기 | 지급받은 카드 열기, 무작위 선수 결과와 고정 포지션 표시 |
| 보유 카드 | 전체 카드와 등급 필터, 이름·사진 수정 |
| 내 선수단 | 상단 야구장 포지션별 카드 배치, 하단 목록과 등록·교체·제외 |
| 설정 | Codex·Claude Code 기록 폴더, 사용량 갱신, 지급·뽑기 규칙 |
| macOS 상태바 | 오늘 사용한 토큰 수, 수동 갱신, 프로그램 열기·종료 |

## 오늘 사용량과 갱신

- 오늘은 Mac의 날짜·시간대를 기준으로 한다.
- 사용 기록 자체의 타임스탬프로 날짜를 나눈다. 오늘 가져온 과거 기록을 오늘 사용량에 넣지 않는다.
- 타임스탬프가 없는 기록은 누적량에만 포함한다.
- 연결한 기록은 프로그램 실행 중 1분마다 갱신하고, 수동 갱신·취소도 지원한다.
- 자정·잠자기 해제·시간대 변경 시 오늘 표시를 갱신한다. 앱을 종료하면 상태바 표시도 종료한다.
- 대화 본문을 앱 데이터에 저장하거나 외부에 전송하지 않는다.

## 기존 데이터 전환

- v0.1의 사용량, 선수 카드, 수정한 이름·사진, 기록 폴더를 유지한다.
- 이전 저장 파일은 백업 후 새 형식으로 변환한다.
- 기존 누적량에도 50M 기준을 적용하며, 기본 루키 9명은 한 번 지급한다.
- 기존 카드의 포지션은 그대로 보존한다. 새 규칙과 맞지 않는 배치는 정리하고, 빈자리는 기본 선수로 채운다.
- 경기 시뮬레이션·육성·합성·거래·대결은 후속 범위다.
