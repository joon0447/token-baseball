# 선수단 기본 초상화 자산

- 생성 방식: Codex 내장 `image_gen` 도구, 2026-09-17.
- 파일: `Sources/TokenBaseball/Resources/player-portraits.png`.
- 용도: 사진을 등록하지 않은 선수의 초상화. 3×3 이미지에서 셀 하나를 실제 비트맵으로 잘라 요청 크기의 썸네일로 표시한다. 상단은 48pt, 하단은 44pt를 사용한다.
- 가상의 야구 선수 9명이며 실제 인물 사진을 사용하지 않았다.
- 기본 선수는 포지션별로 서로 다른 얼굴을 사용한다. 추가 획득 선수는 카드 UUID로 얼굴을 고정한다. 이름이나 저장 형식을 변경하지 않는다.
- 상단 야구장 카드와 하단 목록에서 같은 초상화를 표시한다. 사용자가 등록한 사진이 있으면 우선한다.
- SwiftPM 리소스 번들을 앱의 `Contents/Resources`에 포함하여 오프라인으로 표시한다.

## 생성 프롬프트

```text
Create ONE square game portrait atlas image for a macOS baseball roster, exactly a 3 by 3 grid of nine equally sized square portrait cells, edge to edge with no gutters, no borders, no text or numbers. Each cell contains a different fictional adult male Korean baseball player, head and upper chest, wearing an unbranded navy baseball cap and white baseball jersey with subtle navy piping. Nine clearly distinct faces: varying face shapes, brows, short hair glimpses, some light facial hair, adult ages roughly 23 to 38. All straight-on or very slight three-quarter facing forward, calm confident expressions. Cohesive polished semi-realistic painted sports-game portrait art, natural human facial anatomy and detailed eyes, not icons or silhouettes, not chibi. Each face and entire cap centered with generous space inside its own square, cap top about 10% below cell top and jersey cropped by cell bottom. All nine cells use exactly the same soft pale gray studio background, gentle neutral light. Atlas aligned precisely into equal thirds horizontally and vertically for display in a game. The final asset must contain only the nine portraits, no interface, no stadium, no badges, no logo, no lettering, no watermark.
```
